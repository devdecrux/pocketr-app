# Roadmap

Pocketr is built around a simple idea: make personal and household budgeting clear, trustworthy, and easy to run yourself. This roadmap outlines completed capabilities, active work, and the project's future direction.

The roadmap will change as the project evolves. Items listed here are direction-setting, not fixed release promises.
